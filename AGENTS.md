# Инструкции для работы над проектом

Эти правила действуют для всего репозитория `smaznov-portfolio`.

## Разделение ответственности

- Визуальную оценку сайта выполняет владелец проекта. Не используй компьютерное зрение, скриншоты, запись экрана, управление браузером или другим графическим интерфейсом для визуальной проверки сайта.
- Проверяй техническую корректность изменений: сборку, синтаксис, линтинг и тесты, если соответствующие инструменты есть в проекте. Не утверждай, что интерфейс визуально совпадает с макетом, если это не подтвердил владелец проекта.
- Для чтения исходников и проверки результата используй файлы, командную строку и доступные проверки без графического интерфейса. Figma можно читать как источник спецификаций через API или подключённые инструменты, но не использовать скриншоты для визуальной оценки реализации.

## Проверки перед завершением задачи

1. Просмотри `git status` и diff; не включай в работу посторонние изменения.
2. Запусти `npm run build` после изменений исходников или конфигурации сборки.
3. Проверяй синтаксис изменённых файлов JavaScript через `node --check <файл>`.
4. Если в `package.json` появятся скрипты линтинга или тестирования, запускай относящиеся к изменению проверки. Не представляй отсутствие таких скриптов как успешно пройденный линтинг или тесты.
5. Запусти `git diff --check` и сообщи о фактически выполненных проверках и их результате.

При изменениях только документации достаточно проверить diff и `git diff --check`; сборка и тесты нужны, только если документ затрагивает исполняемую конфигурацию или поведение проекта.
